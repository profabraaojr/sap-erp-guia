# Projetos: PS

Este setor cobre o planejamento e o acompanhamento de projetos. Os códigos estão em [dados/ps.json](../dados/ps.json).

## Fluxo: estrutura ao acompanhamento

1. O projeto é criado e estruturado em elementos WBS, na ferramenta principal (CJ20N).
2. Redes e atividades são definidas (CN21 ou CN01).
3. O orçamento é lançado (CJ30).
4. Confirmações de atividades atualizam o andamento (CN25).
5. A visão geral mostra a estrutura e a situação (CN41N).

## Conceitos-chave

- **WBS (Work Breakdown Structure)**: estrutura analítica que divide o projeto em partes.
- **Rede**: conjunto de atividades com datas e dependências.

## Observação

A descrição de CJ01 varia entre fontes. Confirme no seu sistema.
