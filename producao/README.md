# Produção: PP

Este setor cobre o planejamento e a execução da produção.

## Módulo previsto

- **PP (Production Planning)**: lista de materiais (BOM), roteiros, planejamento de necessidades (MRP) e ordens de produção.

## Conteúdo planejado

- Fluxo previsão, MRP, ordem de produção e apontamento.
- Estrutura da lista de materiais e roteiros.
