# Qualidade: QM

Este setor cobre o controle e a gestão da qualidade. Os códigos estão em [dados/qm.json](../dados/qm.json).

## Fluxo: inspeção à decisão de uso

1. Um lote de inspeção é criado, manualmente ou automaticamente (QA01).
2. Os resultados das características são registrados (QE01).
3. Defeitos encontrados são registrados (QF01).
4. A decisão de uso aprova ou rejeita o lote (QA11).

## Conceitos-chave

- **Decisão de uso**: define se o material é aceito, rejeitado ou segue para outra destinação.
- **Notificação de qualidade**: registra problemas e reclamações (QM01).
